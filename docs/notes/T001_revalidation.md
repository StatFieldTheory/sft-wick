## 核心代码确实改了哪些

T-001 最初的任务记录包含三部分：A：C 表改为 min-time/lag 坐标；
B：两个外部时间都积分时补齐折点分域；C：重新生成 demo2/demo7 结果。
因此它从任务定义起就不只是重新计算 demo2 的表。

数值修复阶段，`src/sft_wick/` 相对 0.6.0 变更了两个文件：

- `evaluate.py`：C 表的坐标、插值、物理边界，以及两个外部时间都积分时的分域。
- `workflow/cache.py`：缓存 schema 升至 3，避免读取旧布局及有缺陷的表。

CI 后续兼容性修复另外修改 `workflow/config.py` 的 hook 序列化导入，见文末。
Wick 配对、图计数、顶点定义、MSR 因子及物理模型没有修改。
Demo2 预算走的是 `c_closed_form_only=True`，且没有 `integrate_over`；
所以仅重算这张预算表不依赖 T-001 的 A/B。两项核心调整有独立的数值收益，
但不应被解释成 demo2 重算本身要求修改物理规则。

进一步将同一修正后的示例核分别交给真正的 0.6.0 源码和当前源码，在
`r=.6,t=1,GL12` 计算三个 FFFK 分量，结果逐位相同：
`[1.61985778351e-7, 1.37080914319e-6, 1.08920899442e-7]`。
两个进程均记录了实际导入路径，未用当前模块冒充发布版。

## 为什么 0.6 的 demo 都通过，仍有改进空间

“通过”指当时的测试点、节点数和容差。原 C 表测试含有非网格点，但没有覆盖
`0 < |t1-t2| < h` 的最差带；并非先前误写的“全部采在网格节点”。
Demo2 已经存在，也不意味着高阶通道在整个时间区间收敛。

| 独立比较 | 0.6.0 | 修复后 | 解释 |
|---|---:|---:|---|
| 混合白噪声 C 的近对角带，最大归一化误差 | 1.10648e-2 | 4.12541e-7 | 参考为独立 Markov 协方差，而非同一套 C 代码 |
| 同一扫描的严格对角线 | 3.05125e-8 | 3.05125e-8 | 本来就准确，不是这次的主要收益 |
| demo7 双外部时间积分，GL12，分通道最大相对误差 | 5.85233e-8 | 5.85640e-15 | 两者都在原容差内；新分域恢复了高精度 |
| demo7 只积分一个外部时间 | 约 1e-15 | 约 1e-15 | 不受新分域影响 |

这些结果来自同时运行旧版本和当前版本的独立对照。Demo8 又重新测量了全部
258 个表格及时间平移验证行，覆盖时变漂移、振荡响应、Matérn、damped-cosine、
Gaussian 和时变白噪声；其余 exact-C 行明确保留历史测量。
例如白噪声 `(0,1)` 二阶 GL12，在 41 个表格节点时误差降至约 2.4e-8。
坐标变化不保证每个粗网格点都更准确：部分平滑核的粗网格误差略增，细化后仍收敛。

## 已纠正的真实回归

1. 通用空间表的 earlier-first 半表已经按原空间顺序计算，查询却再次交换空间坐标。
   秩一高斯场 `phi(x,t)=(t+x*t²)Z` 在 `(0,.25;1,.75)` 应为 0.328125，
   错误结果为 0.234375，偏差 28.57%。现已修正。
2. 矩形 min/lag 表曾在声明的 `t_max` 以外调用物理 R/C；`t_max=1` 时访问了 1.25。
   现在只调用物理三角域内的核；辅助延拓来自表值，不调用域外物理函数。
3. 默认 full-grid 线性插值只使用物理顶点，避免负的辅助延拓污染非负协方差。
   对角单元按时间顺序分成三角形，非对角单元保留双线性规则。
4. 上述保护实现曾重复调用通用插值器，造成查询成本过高；现改为直接读取顶点，
   并只计算查询所属的时间顺序。30,000 个随机查询（含空间外推、三种空间轴数、
   两种交换约定）与优化前逐位一致；标量、空数组、NaN 和序列化也已验证。
5. Demo2 的 `xi00_vs_time` 图没有将非零 FFFK₀₀ 加入总曲线和残差，标题还误写成
   “偶数累积量”。图现与完整预算通道一致；新增用例先复现失败，修复后通过。

同一批 10 万查询、相同表格大小的随机交替计时，中位数为：
单 RGI 13.27 ms、优化前 163.68 ms、当前 19.49 ms。
当前比优化前快约 8.4 倍，但仍比 0.6 使用的单插值器多约 47% 的查询开销。
因此这是明确的精度/成本取舍，不能笼统称为所有方面都更快。

## FFFK 的误差与科学正确性

旧预算中的 22.6% 是 GL10 与 GL14 的差异，不能当作相对于真值的误差界。
其主要问题是晚期积分峰只占整个积分域的一小部分，低节点规则没有解析到它。
另外发现了两个示例问题：FFFK 使用了裸 lambda 的 C，遗漏精确双核 C_eff 的第二项；
旧 κ³ 内层复合求积有额外误差，且没有向外层积分器声明 partner-time 折点。

修正包括：FFFK 改用精确双核 C；κ³/κ⁴ 按所有原始腿时间的排序，将指数核逐段
解析积分；声明折点并逐格加密外层 GL。短区间使用稳定的矩阵级数，简并速率使用
小矩阵指数。跨进程加载辅助模块也有独立测试。

独立参考直接解随机过程的 Itô 矩方程，不调用 sft-wick、Wick 配对或 R/C 积分。
把 M 份独立噪声叠加并除以 sqrt(M)，则协方差保持不变，m 阶累积量乘上
`h^(m-2)`，其中 `h=M^(-1/2)`。F³ 二阶矩含有五个噪声因子，因此：

- `F³ h` 唯一提取 `κ³ C`，即 FFFK；
- `F³ h³` 提取 κ⁵；
- `F² h²` 提取 FFK4；`F⁴ h⁰` 提取 Gaussian FFFF。

参考的单点/双点极限、精确协方差、Gaussian 极限以及另一种显式 replica 提取
均经过核对。原始三重自适应积分与随机化四重 QMC 另外核对了两个收缩核。

在 `r=0,t=50`，独立 FFFK_01 为 `5.50316302389e-5`。
额外运行的 GL40 慢测试确认三个分量都在 `2e-7` 相对误差以内。
这支持被测 Wick/指数/传播子组合的科学正确性；发现的缺陷属于数值实现和示例配置。
它不等于证明整个包对任意输入都无误。

旧表还低估了晚期 FF（约 4–5%）和 FFFF（GL10 约 41%）。现在 FF 使用 GL48，
FK 使用 GL64。每个保存的高阶 L1 值都与独立参考核对：FFFK/FFK4 目标相对误差
1e-4，FFFF 为 1e-3。没有用参考值替换 package 输出。

κ³ 的 1000 个随机输入，旧/新核耗时约 0.575/0.021 s；
κ⁴ 的 100 个输入约 4.389/0.213 s。两次比较使用同一进程、相同输入。

## 最终验收结果

本轮修复和约定范围内的复验已完成。三个高阶通道共 **648 个实际 L1 值**，
涵盖 18 个时间、4 个空间距离、3 个分量；全部通过独立参考阈值。
每个非零通道均单独检查相对误差，理论为零的通道检查绝对误差。

| 通道 | 格数 | GL 节点 | 最大相对误差 | 验收阈值 |
|---|---:|---:|---:|---:|
| 0 阶 | 1188 | 48 | 2.8585e-14 | 1e-7 |
| FF | 1188 | 48 | 1.5294e-10 | 1e-7 |
| FK | 1188 | 64，另以 96 核对 | 5.6253e-14 | 1e-7 |
| FFK4 | 216 | 12–29 | 8.7880e-5（0.00879%） | 1e-4 |

`5.50316302389e-5`，相对误差 1.9333e-5；另跑的 GL40 慢测试达到更严格的
2e-7。预算精度和单点高精度测试的节点数不同，未混写成同一结果。

最终 NPZ 的 80 个数组全部有限；10 个原模拟/外推数组逐项与修复前相同。
预算使用实际 L1 结果；重组缓存时重新检查了每格的键、通道和参考误差，
`budget_meta.json` 记录来源，未用参考填充理论列。

`pytest tests/test_generated_docs_in_sync.py tests/test_catalog_current.py -q`
最终 **8 passed**，2.20 s；包括对角图必须包含 FFFK 的新增回归检查。

模拟并没有因此完全吻合：在 `r=0,t=15`，模拟外推为
`4.37617e-4 ± 1.34199e-5`，所列理论总和为 `3.99072e-4`，残差约 **+2.87σ**。

所有剩余残差。该截断/模拟问题没有被伪装成“数值积分尚未算准”。

## 2026-09-14 补充：2.87σ 的范围与下一步

2.87σ 特指 demo2 的 `xi01(r=0,t=15)`，使用当前逆方差加权及两步长外推后
给出的 Monte Carlo 标准误。它不是 package 的通用精度指标，也没有包括微扰
截断、遗漏累积量、时间步外推偏差和剔除轨迹的影响。因此不应把它解读为
“核心科学实现以 2.87σ 被否定”，也不能反过来断言剩余差异一定全由截断造成。
完整不确定度需要同时考虑随机误差和偏差；参见
[NIST 的不确定度分析说明](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc52.htm)。

针对该点重新核对相同通道：package 的 `FK+FFFK` 为 `3.990717627230993e-4`，
独立矩方程为 `3.990717607390856e-4`，差 `1.9840e-12`。
模拟残差 `3.8546e-5` 比它大约 1940 万倍。即使以独立参考完全替换这两个
