Citing sft-wick
===============

If you use **sft-wick**, please cite the paper that describes the
formalism and the package:

   Zheng Zhang, *sft-wick: A formalism and package for Feynman-diagram
   expansion and evaluation in stochastic field theories*,
   `arXiv:2606.19480 <https://arxiv.org/abs/2606.19480>`_ (2026).

BibTeX entry, as exported by arXiv:

.. code-block:: bibtex

   @misc{zhang2026sftwickformalismpackagefeynmandiagram,
         title={sft-wick: A formalism and package for Feynman-diagram expansion and evaluation in stochastic field theories},
         author={Zheng Zhang},
         year={2026},
         eprint={2606.19480},
         archivePrefix={arXiv},
         primaryClass={physics.comp-ph},
         url={https://arxiv.org/abs/2606.19480},
   }

Software archive
----------------

The software is archived on Zenodo.
`DOI:10.5281/zenodo.20776358 <https://doi.org/10.5281/zenodo.20776358>`_
is the *concept* DOI: it covers all versions and resolves to the most
recent release.  To reference the version your results were produced
with, cite that release's own version DOI, listed under "Versions" on the
Zenodo record page.  The repository's ``CITATION.cff`` feeds GitHub's
*Cite this repository* button with the same metadata.
